# Public Presentation Links

Canonical public URL for every deck in `presentations/`. Link style depends on
format, since GitHub serves raw `.html` as `text/plain` (won't render) while
`.md` renders fine on github.com directly:

- **Markdown deck** → GitHub blob link: `github.com/Encryptioner/blogs/blob/master/<path>`
- **HTML deck** → raw-content proxy link: `encryptioner.github.io/public-websites/any-page/#raw.githubusercontent.com/Encryptioner/blogs/refs/heads/master/<path>`
